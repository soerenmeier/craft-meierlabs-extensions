# Meier Labs Extensions for Craft CMS

## Overview

Meier Labs Extensions is a small plugin containing little tweaks and extensions for Craft CMS.

## Features

- Hide more ul and ol options in CKEditor
- Set cke font-size to 16px
- `mock-assets` console command to replace asset files with dummy files

This is the Craft 4 version (branch `craft-4`). The Craft 5 version on `main`
also has a simpler Link field design and ungrouped Matrix buttons; Craft 4 has
no Link field and already shows every Matrix block type as its own button.

## Installation

Via the [Craft Plugin Store](https://plugins.craftcms.com/meierlabs-extensions?craft4) or the command-line:

```bash
composer require soerenmeier/meierlabs-extensions -w && php craft plugin/install meierlabs-extensions
```
